# CV Generator

Generate a polished PDF CV from a Markdown file using Python.

## Install

Python 3.14 or newer is required. Install the project and its dependencies in a virtual environment:

```sh
python -m venv .venv
source .venv/bin/activate
python -m pip install -e .
```

WeasyPrint may need system libraries on some operating systems. See the [WeasyPrint installation guide](https://doc.courtbouillon.org/weasyprint/stable/first_steps.html#installation) if installation reports missing dependencies.

## Use

```sh
cv-generator path/to/cv.md
```

This writes `path/to/cv.pdf`. Choose another destination with `--output`, and provide a custom stylesheet with `--css`:

```sh
cv-generator path/to/cv.md --output build/resume.pdf --css my-style.css
```

The stylesheet is applied on top of the bundled print styles, so it can override colors, fonts, spacing, and layout. Relative file references in the Markdown and CSS are resolved from their respective input files.

An example CV and matching stylesheet based on the sample layout are in `examples/`:

```sh
cv-generator examples/sample_cv.md --css examples/sample_cv.css --output build/sample-cv.pdf
```

## Security

Only render Markdown and CSS that you trust. Embedded HTML and CSS resources can cause WeasyPrint to read local files or fetch network URLs while generating the PDF. This CLI is intended for trusted input and is not hardened for untrusted documents. See the [WeasyPrint security guidance](https://doc.courtbouillon.org/weasyprint/latest/first_steps.html#security).

## Development checks

Install the development tools with:

```sh
python -m pip install -e '.[dev]'
```

Format the Python code with Black and run the Ruff linter and mypy type checker:

```sh
black cv_generator tests
ruff check cv_generator tests
mypy
```

Run the automated PDF and CLI checks with coverage reporting:

```sh
coverage run -m unittest discover -s tests -v
coverage report -m
```

## Markdown

Use regular Markdown. Headings become section headings; paragraphs, lists, emphasis, and links are preserved. No fixed section names or CV-specific schema are required. For example:

```markdown
# Alex Example

alex@example.com · Budapest

## Experience

### Software Engineer — Example Co.

2022–Present

- Built [the product](https://example.com) used by thousands of people.
- Improved service reliability.
```

Insert a page break on its own line with `<!-- pagebreak -->`:

```markdown
## Professional Experience

...

<!-- pagebreak -->

## Education

...
```

The generator checks whether each requested break begins at the top of a PDF page and prints a warning if the CSS layout prevents it.

The default stylesheet is `cv_generator/styles/default.css` in the installed package. Copy it to customize the full layout, or pass a small CSS file to override selected rules.
